# お薬手帳QRコードの読み取りの工夫

- 関連コミット: `a91e6ce`（`public/js/pages/medications.js`）

## 問題
- 薬局で発行されるお薬手帳のQRコード（JAHIS形式）は Shift_JIS という文字コードで書かれている。
- 使用しているライブラリ jsQR は、UTF-8 として読めないデータを空文字にしてしまうため、お薬手帳のQRコードをカメラに映しても何も反応しなかった。

## 工夫
- jsQR が返す生のバイト列（`binaryData`）を受け取り、ブラウザの `TextDecoder` で文字に戻すようにした。
- 文字コードは「UTF-8 → Shift_JIS」の順に試す。
  - Shift_JIS のデータを UTF-8 として読むとほぼ必ずエラーになるので、判別できる。
  - 逆の順番（UTF-8 のデータを Shift_JIS として読む）はエラーにならず文字化けすることがあるため、この順番にした。
  - `fatal: true` を指定し、読めなかったときは文字化けした結果を使わずに次の文字コードを試す。
- 読み取った文字列はサーバーの `jahisParser.js` で解析し、お薬の名前などを入力欄に反映する。
