# お薬手帳QRコード（JAHIS形式）の読み取りで工夫したこと

## 実物のQRコードを読み取って、その中身に合わせてパーサーを作り直した
- 最初は仕様書から推測した項目の並び（レコード番号「21」に薬品名・用法・用量が1行で並ぶ）で解析していたが、実際の医院の明細書のQRコードは読み取れても「医薬品情報が含まれていません」となった。
- 開発者ツールのコンソールに読み取った内容を一時的に出して確かめたところ、実データ（JAHISTC06）では薬の情報が次の3種類の行に分かれていた。
  - `201`（薬品）: RP番号・薬品名称・用量・単位
  - `301`（用法）: RP番号・用法名称・調剤数量（例: 24）・調剤単位（例: 日分）
  - `311`（用法補足）: RP番号・補足の説明
- 薬と飲み方は「RP番号」でつながっている（同じ飲み方の薬のまとまり）。そこで、用法・補足を先に RP番号ごとに集め、同じ RP の薬それぞれにメモとして付けるようにした。1つの RP に薬が複数あっても、すべての薬に同じ飲み方が付く。
- 患者名・生年月日・住所・医療機関・医師などの行（`1`, `11`, `15`, `51`, `55` など）は個人情報なので、アプリでは読まないようにした。
- 確認用のログは、パーサーの調整が終わった時点で削除した。本番のサイトで動作を確かめる運用なので、個人情報を含む内容がコンソールに出続けないようにするため。

## 利用者に分かりやすい形にそろえた
- QRコードの中の文字は全角英数字（「１０ｍｇ」「ｇ」）で書かれているため、Unicode の NFKC 正規化で半角にそろえた。読みやすくなるだけでなく、単位「ｇ」がアプリの単位の選択肢「g」と一致し、プルダウンで自動的に選ばれるようになった。
- 塗り薬の調剤数量「1調剤」は高齢の利用者には意味が分かりにくいので、メモには「◯日分」「◯回分」のときだけ載せるようにした。
- 用法名称には薬局の専門的な書き方がそのまま入っているため、利用者に分かる書き方に言い換えた。
  - 「分1(朝食後服用)」の「分1」は「1日の量を1回に分けて飲む」という略語で、利用者には意味が分からない。「分N」を「1日N回」に置き換え、「1日1回(朝食後服用)」と表示する。
  - 塗り薬の「1日2回～1回」（2回から始め、良くなったら1回に減らす意味）は、一般的な「少ない〜多い」の順にそろえて「1日1〜2回」と表示する。
  - 全角→半角の変換で波線が「~」になるため、読みやすい「〜」に戻す。
- 確認画面にメモの欄を加え、読み取った飲み方を登録前に確認・修正できるようにした。

## カメラの解像度を指定して、細かいQRコードを読めるようにした
- パーサーを直したあと、PCのカメラで同じQRコードが読み取れなくなった（カメラは映るが反応しない）。
- `getUserMedia` で解像度を指定しないと、PCのカメラは 640×480 程度で起動することが多い。お薬手帳のQRコードは薬4件分でも十数行の情報を含むため、模様が非常に細かく、この解像度では模様1マスが数ピクセルしかなく、読めるかどうかが映し方しだいになっていた。
- `width: { ideal: 1920 }, height: { ideal: 1080 }` を指定し、カメラが出せる範囲でなるべく高い解像度を求めるようにした。`ideal` にしたので、対応していないカメラでもエラーにならずに起動する。
- ただし、解像度が 1280×720 以上になったことをコンソールで確かめても、ノートPCでは読み取れなかった。一方、スマートフォン（Google Pixel 10a）ではすぐに読み取れた。ノートPCの内蔵カメラはピントが固定（顔の距離向け）のものが多く、近づけるとぼやけ、離すと小さすぎるためと考えられる。解像度を上げたことは無駄ではないが、主な原因はカメラのピントだった。
- 10秒たっても読み取れないときは、映し方のコツ（明るい場所で、大きく、まっすぐ）と「パソコンのカメラでは読み取れないことがあります。そのときはスマートフォンでお試しください。」を画面に出すようにした。高齢の利用者が「反応しない」まま困らないようにするため。
- 原因の切り分けには、個人情報を含まない情報（カメラ映像の大きさ、QRコードが見つかったか）だけを一時的にコンソールへ出した。確認が終わった時点で削除した。

## 関連（Shift_JIS への対応）
- JAHIS形式のQRコードは日本語が Shift_JIS で書かれている。jsQR は UTF-8 として読めないと文字列を空にしてしまうため、元のバイト列から `TextDecoder` で UTF-8 → Shift_JIS の順に試して文字に戻している。
