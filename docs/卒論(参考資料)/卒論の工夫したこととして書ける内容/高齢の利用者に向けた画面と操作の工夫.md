# 高齢の利用者に向けた画面と操作の工夫

## 1. 場面ごとに必要なボタンだけを出す
- 関連コミット: `10c98dc`
- 服薬を記録する画面で、ボタンを1つにまとめるのではなく、場面に応じて出すボタンを変えた。
  - カメラ起動前: 「カメラを起動する」「映像なしで『飲んだ』を記録」「今回はスキップする」
  - 録画中: 「飲みました（映像つきで記録する）」「今回はスキップする」（紛らわしい「映像なしで記録」は隠す）
- ボタン名に「映像つきで記録する」と書き、違いがひと目で分かるようにした。
- `hidden` を付けた要素が必ず非表示になるCSSのルールを追加し、ほかの画面の同じ不具合もまとめて防いだ。

## 2. 録画は30秒で自動的に記録する
- 関連コミット: `af4645d`
- 録画を止めるボタンを押し忘れても記録できるように、録画は30秒で自動的に終わって記録されるようにした。

## 3. アプリを開いているあいだの服薬アラーム
- 関連コミット: `ae4db5f`（`public/js/alarm.js`）
- 服薬時刻になると、画面いっぱいに「カメラを起動する」ボタンを出し、記録するか「あとで」を押すまで音・読み上げ・振動を繰り返す。プッシュ通知だけでは気付きにくい利用者を想定した。
- ログイン後のすべての画面で動き、ホーム以外の画面からでもボタン1つで記録画面へ移動できる。
- 「あとで」は5分後にもう一度知らせる。服薬時刻から60分を過ぎたら、アラームではなくホームの案内に切り替える。

## 4. 記録タブを見やすくした
- 関連コミット: `331349d`, `80791a0`, `ed8a63a`
- 1日ごとに枠で区切り、新しい順に並べた。記録した時刻を大きく表示した。
- 予定時刻を過ぎても記録がない予定には「飲み忘れ」のバッジを付け、ひと目で分かるようにした。スキップにも記録時刻を表示した。
- 1日ごとの枠は、最初は背景より少し濃い紙色と薄い罫線で作ったが、ページの背景と色が近く、区切りが分かりにくかった。そこで枠線を藍色の太線にし、日付の見出しを藍色の帯に白い文字で表示するように改めた。色の明暗の差（コントラスト）をはっきりさせることで、視力が落ちてきた高齢の利用者でも、どこからどこまでが同じ日の記録かを見分けやすくしている。家族の記録を表示しているときは、枠と帯もテラコッタ色に変わり、ほかの画面の配色とそろえている。
- 記録のカードは「時刻｜薬の名前と状態｜ボタン（映像を見る・編集）」を横に並べていたが、スマートフォンでは「映像を見る」ボタンが出ると薬の名前の欄が細くなり、名前が1〜2文字ずつ折り返して読みにくくなっていた。パソコンの画面では気づかず、実際のスマートフォンで開いて分かった問題である。そこで、横幅480px以下の画面ではボタンをカードの下の段に横並びで置き、時刻と薬の名前に横幅いっぱいを使わせるようにした（`public/css/logs.css` のメディアクエリ）。ボタンも横幅いっぱいに広がるので、指で押しやすくなった。
- 記録のカードには薬の名前しか出ておらず、「何錠飲む予定だったか」はお薬タブを開かないと分からなかった。家族が記録を見て確かめるときにも、量が分かるほうが安心できる。そこで、お薬タブで登録した用量・単位（例：「1 錠」）を薬の名前の下に小さく表示するようにした（`public/js/pages/logs.js` の `renderLogCard`）。表示の形はホーム・お薬タブと同じ「用量 単位」にそろえ、どの画面でも同じ見え方になるようにした。データは記録の一覧を取る API がすでに返していたため、サーバー側の変更は要らなかった。
  - ただし、表示しているのは「いま登録されている」用量であり、記録した当時の用量ではない。あとで用量を変えると、過去の記録の表示も新しい用量に変わる。当時の量を正確に残すには、記録を作るときに用量を `medication_logs` へ写し取っておく必要がある（今後の課題）。

## 5. 入力の手間と間違いを減らす
- 関連コミット: `c8ae8ea`, `b03b444`, `0fd2d00`
- お薬の単位（錠・包など）を自由入力ではなくプルダウンで選べるようにした。
- パスワード入力欄に「表示／非表示」の切り替えを付け、入力した内容を確かめられるようにした。
- 登録画面の入力チェックとエラーの表示を見直した。

## 6. 使わない機能は画面に出さない
- 関連コミット: `3d874e3`（マイグレーション `0005_watch_features.sql`）
- 登録時に「使い方」（見守られる／見守る／自分のお薬の管理だけ）を選んでもらい、使わない操作（招待コードの入力や家族への表示の切り替えなど）を画面に出さないようにした（表示中の人が分かるよう、「自分」のボタンだけは常に出す。7. を参照）。あとからマイページで変更できる。
- 画面から隠すだけでなく、データベースのトリガーでも「機能を使わない人が見守りを始める」「見守りの相手がいるのに機能を OFF にする」ことを止めている（画面から消えたのに見守りが続く、という食い違いを防ぐ）。

## 7. 見ている人が自分か家族かを、色で区別する
- 関連コミット: `ae4db5f`, `53e01e4`, `669b41b`（`public/js/viewTarget.js`）
- ホーム・お薬・記録のタブで、表示する人（自分／見守っている家族）を切り替えられるようにした。選んだ人はタブを移っても引き継ぐ。
- 家族の情報を表示しているあいだは画面の配色を変え、自分の情報と取り違えないようにした。
- 見守り画面の「見守っている／見守られている」家族の切り替えは、最初はプルダウンで作ったが、操作が分かりにくいため2つの大きなボタンに改めた。
- 切り替えのボタンは、最初は見守っている家族がいるときだけ表示していた。しかし、家族の画面を見たことがある人や、あとから見守りを始めた人にとっては、ボタンが出たり消えたりすると「いま誰の情報を見ているのか」が分かりにくくなる。そこで、見守っている家族がいない場合も「自分」のボタンだけは選択された状態で常に表示し、自分のお薬の情報を見ていることが一目で分かるようにした（`public/js/viewTarget.js` の `renderSwitcher`）。切り替える相手がいないので、押しても表示は変わらない。

## 8. 招待コードを書き写しやすくした
- 関連: `0006_regenerate_invite_code.sql`、`src/routes/careGroups.js`
- 招待コードは、電話や紙で家族に伝えることも想定される。以前は16進数（0〜9 と a〜f）の小文字だった。
- 見間違えやすい文字（0 と O、1 と I と L）を使わない、英大文字と数字の8文字にした。
- 入力するときは大文字・小文字を区別せず、書き写したときに入りやすい空白やハイフンも無視するようにした（入力欄は最初から大文字になるようにした）。
- 文字の種類を31種類に絞っても、8文字で約8,500億通りあり、当て推量で他人のコードを当てるのは現実的でない。
