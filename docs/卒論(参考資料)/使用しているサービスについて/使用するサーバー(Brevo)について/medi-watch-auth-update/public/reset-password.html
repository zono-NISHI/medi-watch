メールをご確認ください


あてに、パスワード再設定のメールをお送りしました。

メールの「パスワードを決め直す」ボタンを押して進んでください。
ボタンがうまく使えないときは、メールに書かれた6桁の数字を下に入力してください。

メールが届かないときは

届くまで数分かかることがあります。「迷惑メール」のフォルダも、ご確認ください。 入力したメールアドレスが、ご登録のものと違う場合も届きません。

送信元：

携帯会社のメール（docomo・au・SoftBank など）は、受信の設定によっては届かないことがあります。 上のアドレスからのメールを受け取れるように設定するか、ご家族にご相談ください。
