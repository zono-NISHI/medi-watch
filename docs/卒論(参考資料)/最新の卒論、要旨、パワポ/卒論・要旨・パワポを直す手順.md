# 卒論・要旨・パワポを直す手順

このフォルダの卒論本文・要旨・発表スライドを、Claude Code に頼んで直すときの手順です。
道具（スクリプト）とスキルを用意してあるので、毎回一から調べ直さずに直せます。

## 先に準備すること

- **Word と PowerPoint で、このフォルダのファイルを閉じておく。** 開いたままだと上書きできず、「_修正2」のような別名のファイルが増えます。
- PC に Python 3・Node.js・Word・PowerPoint が入っていること。
- スライドを作り直す PC で初めて作業するときは、`scripts/thesis/slides` で `npm install` を1回実行する。

## どの場面で、どのスキルを使うか

| やりたいこと | 使うスキル | 頼み方の例 |
|---|---|---|
| 論文やスライドに古い記述がないか調べたい（直さない） | `/thesis-check` | 「/thesis-check 前回の修正以降の変更だけ見て」 |
| 卒論本文・要旨（Word）を直したい | `/thesis-edit` | 「/thesis-edit 本文の4.5節に○○を追記して」 |
| 発表スライド（PowerPoint）を直したい | `/thesis-slides` | 「/thesis-slides 6枚目の『8:30』の説明を短くして」 |

スキル名を書かなくても、「卒論の○○を直して」のように頼めば、Claude Code が合うスキルを選びます。確実に使わせたいときだけ `/スキル名` を付けてください。

## おすすめの進め方

### アプリを直したあとで、論文にも反映したいとき

1. `/thesis-check` で、食い違いの一覧を出してもらう。
2. 一覧を見て、直す項目を選ぶ（「1・3・4番を直して」のように伝える）。
3. `/thesis-edit` で本文と要旨を直す。
4. 同じ内容がスライドにもあれば、`/thesis-slides` で直す。
5. Word と PowerPoint で開いて、見た目を確かめる。

### 直したい箇所が決まっているとき

- 手順1・2を飛ばして、`/thesis-edit` か `/thesis-slides` に「どの節（何枚目）の、何を、どうするか」を箇条書きで伝える。これがいちばん速いです。

### 提出用の PDF が要るとき

- 「/thesis-edit 本文と要旨を PDF にして」と頼む（Word のファイルと同じフォルダに書き出されます）。

## 自分で決めて伝える必要があること

次の内容は、Claude Code がソースコードから判断できません。聞かれたら答えるか、先に伝えてください。

- 動作確認をどこまで実施したか（本文の表5.1の「状況」）
- 実施していない検証（iOS、第三者による評価など）
- 反省点・感想など、自分の考えを書く部分

## 気を付けること

- **スライドを PowerPoint で直接直した内容は、スクリプトで作り直すと消えます。** 8枚目に貼った画面の写真も同じです。作り直しを頼む前に、「○枚目は自分で直してある」と伝えてください。
- 卒論本文・要旨は、Word で手直ししてもかまいません。次に直すときは、このフォルダにある最新のファイルを元にします。
- 本文を直したら、要旨とスライドにも同じ記述がないかを確かめます（スキルが確認しますが、最後は自分でも見てください）。

## ファイルの場所

| 場所 | 中身 |
|---|---|
| このフォルダ | 最新の卒論本文・要旨（.docx）と発表スライド（.pptx） |
| `.claude/skills/thesis-check/` ほか | スキル（Claude Code への手順書）3つ |
| `scripts/thesis/dump_docx.py` | Word の文章を段落ごとに書き出す |
| `scripts/thesis/apply_edits.py` | 修正内容ファイルを Word に適用する |
| `scripts/thesis/finalize.ps1` | 目次のページ番号を更新する。`-Pdf` で PDF も作る |
| `scripts/thesis/edits/` | これまでの修正内容の記録（日付つき） |
| `scripts/thesis/slides/build_slides.js` | 発表スライドの中身（文言と、話す内容のノート） |
| `scripts/thesis/slides/export_slides.ps1` | スライドを画像に書き出す（見た目の確認用） |

## 発表スライドについて（2026-11-17 に作成）

- 持ち時間12分・13枚。各スライドのノートに、話す内容と時間の目安を入れてあります。
- 8枚目「実際の画面（デモ）」の3つの枠には、アプリの画面の写真を自分で貼ってください（ホーム／撮影画面／家族の表示）。
- 12枚目の「12項目すべてを確認」は、本文の表5.1に合わせています。
