# 卒論発表スライドの修正

スライドは `scripts/thesis/slides/build_slides.js` から作っている。**このファイルを書き換えて作り直す**（.pptx を直接いじらない）。出力先は `docs/卒論(参考資料)/最新の卒論、要旨、パワポ/2370354_西薗正彦_卒業論文発表.pptx`。

## 前提

- Node.js と PowerPoint が入っている PC で行う。
- 初回だけ `scripts/thesis/slides` で `npm install` を実行する（`node_modules/` は Git に入れていない）。
- **.pptx を PowerPoint で開いたままだと上書きできない。** 最初に利用者へ「PowerPoint を閉じてください」と伝える。
- **利用者が PowerPoint で直接直した内容（貼った写真など）は、作り直すと消える。** 作り直す前に、直接直した箇所がないかを利用者に確かめる。あるときは、その内容を `build_slides.js` に取り込むか、利用者に PowerPoint で直してもらうかを相談する。

## 手順

1. `scripts/thesis/slides/build_slides.js` の該当するスライド（`// ============ N. 題名 ============` で区切ってある）を書き換える。話す内容は各スライドの `addNotes` に入っているので、文言を変えたらノートも合わせる。
2. 作り直す。
   ```
   cd scripts/thesis/slides
   node build_slides.js
   ```
3. 見た目を確かめる。1枚ずつ画像に書き出して、すべて読む。
   ```
   powershell -ExecutionPolicy Bypass -File export_slides.ps1 -Pptx "<発表.pptx>" -OutDir "<一時フォルダ>"
   ```
   見るところ: 文字が枠からはみ出していないか、単語の途中で不自然に折り返していないか、要素が重なっていないか。直したら、作り直して見直す。

## 守ること

- 持ち時間は12分・13枚（1枚あたり約55秒）。枚数を増やすときは、どれかを減らすか、利用者に時間を確かめる。ノートの【約○秒】の合計が持ち時間に収まるようにする。
- 配色はアプリと同じ（藍色・テラコッタ・紙色）。色の定数はファイルの先頭にある。フォントは Meiryo、本文は 14pt 以上。
- スライドの内容は、卒論本文（最新版）とソースコードに合わせる。本文にない数字や事実を足さない。
- 8枚目「実際の画面（デモ）」の枠は、利用者が画面の写真を貼る場所。写真のファイルをもらったら、`addImage` で枠の位置に入れる。
- `pptxgenjs` はルートの `package.json` に入れない（Render のビルドに影響させないため。`mobile/` と同じ考え方）。
- 終わったら、`CLAUDE.md` の決まりどおり、変更したファイルの一覧・コミットメッセージ案・PR 説明文案を示す。git の操作はしない。
